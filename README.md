# custom-apreblanc

Repositorio de módulos personalizados para Apreblanc sobre Odoo 17.

## Módulos

| Módulo | Descripción |
|--------|-------------|
| [apreblanc_credit_control](apreblanc_credit_control/README.rst) | Control de crédito simplificado: análisis de deuda vencida, envío de recordatorios por email e historial de comunicaciones en la ficha del cliente. |
| [apreblanc_probabilty](apreblanc_probabilty/) | Añade campo de probabilidad y % de margen a los pedidos de venta. |
| [apreblanc_service_project_control](apreblanc_service_project_control/README.rst) | Genera proyectos operativos desde pedidos de venta y controla horas imputadas sobre servicios. |
| [apreblanc_sale_order_expedient](apreblanc_sale_order_expedient/) | Expediente en pedidos de venta. |
| [sale_exporter_importer](sale_exporter_importer/) | Exportación e importación de pedidos de venta. |
| [xtendoo_onedrive_connector](xtendoo_onedrive_connector/) | Conector con OneDrive. |
